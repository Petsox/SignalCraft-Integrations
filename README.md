# SignalCraft-Integrations

This mod is an addon for [SignalCraft](https://github.com/Petsox) integrating it with other Minecraft mods. It requires SignalCraft to be installed, and adds extra blocks that let SignalCraft's signalling equipment communicate with the redstone/computer mods below. Each integration is only registered if the corresponding mod is detected, so this addon works fine even if you only have some of the supported mods installed.

You can get it on [CurseForge](https://www.curseforge.com/minecraft/mc-mods/signalcraft-integration)

## Supported mods

- **[ProjectRed](https://www.curseforge.com/minecraft/mc-mods/projectred)** (Integration) — bundled-cable redstone controllers:
  - Bundled Controller
  - Bundled Universal Controller
  - Bundled Advanced Controller
  - Bundled Crossing Controller
  - Bundled Receiver
- **[OpenComputers](https://www.curseforge.com/minecraft/mc-mods/opencomputers)** — computer-driven digital controllers:
  - Digital Controller
  - Digital Universal Controller
  - Digital Crossing Controller

## Requirements

- Minecraft 1.7.10
- Minecraft Forge
- [SignalCraft](https://github.com/Petsox) (required)
- ProjectRed and/or OpenComputers (optional, enables the respective integration)

# SignalCraft-Integrations (Česky)

Tento mod je doplněk (addon) pro [SignalCraft](https://github.com/Petsox), který jej propojuje s dalšími mody pro Minecraft. Vyžaduje nainstalovaný SignalCraft a přidává bloky, díky nimž může návěstní technika ze SignalCraftu komunikovat s níže uvedenými redstonovými/počítačovými mody. Každá integrace se zaregistruje pouze tehdy, pokud je odpovídající mod nalezen, takže tento doplněk funguje i v případě, že máte nainstalovaný jen některý z podporovaných modů.

## Podporované mody

- **[ProjectRed](https://www.curseforge.com/minecraft/mc-mods/projectred)** (Integration) — řadiče pro svazkované (bundled) redstonové kabely:
  - Bundled Controller
  - Bundled Universal Controller
  - Bundled Advanced Controller
  - Bundled Crossing Controller
  - Bundled Receiver
- **[OpenComputers](https://www.curseforge.com/minecraft/mc-mods/opencomputers)** — digitální řadiče ovládané počítačem:
  - Digital Controller
  - Digital Universal Controller
  - Digital Crossing Controller

## Požadavky

- Minecraft 1.7.10
- Minecraft Forge
- [SignalCraft](https://github.com/Petsox) (povinné)
- ProjectRed a/nebo OpenComputers (volitelné, zapíná příslušnou integraci)
